# 相澤家（居住ビルの毎日）アプリ

会話はClaude API、画像はOpenAI APIで動く、スマホ向けのWebアプリです。
データ（資料・会話・写真・APIキー）は、使っている端末のブラウザの中にだけ保存されます。

## iPhoneだけで公開する（GitHub Pages）

1. このzipをiPhoneの「ファイル」アプリに保存し、タップして展開する（フォルダができます）
2. Safariで github.com にログイン →「＋」→「New repository」
   - 名前を入れる（例：aizawa-family）、**Public** を選んで「Create repository」
3. できた画面の「uploading an existing file」をタップ →「choose your files」
   - 「ファイル」が開いたら、展開したフォルダを開く → 右上「…」→「選択」→ 左下「すべて選択」→「開く」
   - 72個のファイルが並んだら、下の「Commit changes」をタップ（アップロードに少し時間がかかります）
4. リポジトリ上部の「Settings」→ 左メニュー（またはページ内）の「Pages」
   - 「Branch」を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分待つと、Pagesの画面に `https://ユーザー名.github.io/aizawa-family/` が表示されます
6. そのURLをSafariで開き、共有ボタン →「ホーム画面に追加」

Publicで公開されるのはアプリのプログラムと背景・アイコン画像だけです。資料・会話・写真・APIキーは各自の端末にしか保存されません。
※ ホーム画面に追加して使うと、iPhoneがデータを消しにくくなります。

## はじめに一度だけやること

1. HOME → **Settings** で、Claude APIキー と OpenAI APIキー を入れて「保存」
2. HOME → **Prompt Vault** →「txtを取り込む」で、プロジェクトの資料をまとめて選ぶ
   - ストーリープロンプト・LIVEMODE・世界観は自動で「常時」に設定されます
3. STORY →「＋」→「会話ログを取り込む」で、直近の会話ログを読み込むと続きから再開できます

## 画面

- **HOME**：時刻・同期、人物の現在地（RESIDENCE MAP）、予定、家族グループLINE
- **LIVE**：現実の時刻と同期した生活。部屋をタップ／「移動」で移動。時間が進んでいれば開いた時に自動更新
- **STORY**：通常ストーリー。【思い出】で思い出資料に追記（40手ごとにも自動）。ナレーター相談・【物語に戻る】も使えます
- **DM**：各人物との個別DMと家族グループLINE。LIVE中に人物からDMが届くこともあります
- **FEED**：うみとして投稿、または家族の投稿をAIが生成（Instagram相当）
- **ALBUM**：写真の参照BANK。人物ごとに OK / NG をつけると画像生成に使われます

## バックアップ

Settings →「書き出す」で全データ（APIキー以外）を1つのファイルに保存できます。
機種変更の時は、新しい端末で「読み込む」を使ってください。

## 料金の目安

会話は使った分だけ Anthropic に、画像は OpenAI に支払います。
1回の会話で送る量は、Settings の「毎回送る直近履歴」で調整できます。前回の使用トークン数は STORY 画面の上に表示されます。
